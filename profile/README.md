## Thirdline

A student-run software studio in Washington, DC. We take problems apart and build AI-driven software to solve them, for schools, businesses, nonprofits, or anyone with a problem worth solving.

### What we've shipped

**[Tapin](https://github.com/Thirdline-LLC/NFC-Attendance-Scanner)**: an attendance kiosk for schools. A student taps an ID card on a USB NFC reader and the tap is recorded on that device. No server, no accounts, no student data in the cloud. The school's own workbook stays the system of record. Runs as a Mac app, an Android APK and a PWA, and is heading into teacher testing at St. John's College High School.

### How we build

- **Start with the problem.** Talk to the people who feel it, break it into pieces, and ship the smallest thing that fixes the first piece.
- **Specs before code.** Every change starts as a written spec and a ticket, then goes through a pull request, review and CI before it merges.
- **Student data stays put.** School tools keep records on the device or in the school's own systems. None of it goes into our repositories.
